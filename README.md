# Madhurima Birthday Gift Website

## Files to upload to GitHub
Upload all files in this folder to the main folder of a public repository.

- `index.html`
- `madhurima.jpeg`
- Optional: add your own legal MP3 music file and name it `young-and-beautiful.mp3`.

## Important music note
The webpage is set up to play a file called `young-and-beautiful.mp3` when the visitor presses the music button. I did not include the Lana Del Rey recording because it is copyrighted. Only upload music you own or are licensed/authorized to publish.

## GitHub Pages
Open repository **Settings > Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The user chooses any date first. The website then counts down to 20 October in that selected year (or next year if that date already passed). When the countdown ends, the birthday message and fireworks appear.
